# Idop

Idop is a single-player-first cozy mobile game. Players build a small Capsule,
launch it into a stylized world, and get it back visibly changed with a permanent
memory committed to an active archive. The Hearth is the player's home companion:
it reads the world, shapes launches, reacts to returns, and evolves with the archive.

This repository is the first-build monorepo described by `AGENTS.md`,
`BACKLOG.md`, and the design docs under `docs/`.

## Commands

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm test:engine
pnpm dev:server
pnpm dev:mobile
```
